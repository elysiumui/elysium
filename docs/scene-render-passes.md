# Genuine scene preview passes and render jobs

The former batch-render path rendered only one placement and produced tinted grayscale copies of beauty under diffuse/specular/normal/depth filenames. That code is removed. Native Render and Scene Preview Batch now use the shared scene camera, composed visible meshes, authored material slots/images/normals, lighting and 60 fps pose keys. Rendering runs in a background job with completion, progress, cancellation and failure status.

## Output contract

This is the direct-light/approximate-IBL preview renderer, explicitly labeled in the UI and manifest. It does not claim converged path-traced output. Square area lights retain the documented 16-sample integration. A frame's `passes.npz` always contains float arrays: `beauty_linear`, `diffuse`, `specular`, `emission`, `normal`, `depth`, plus boolean `mask`. Diffuse/specular separate actual BRDF/IBL contributions; clearcoat belongs to specular and attenuates the underlying lobes. Emission is the material's emitted radiance. Diffuse + specular + emission reconstructs linear beauty within floating-point precision. Normals are signed unit world-space Y-up shading normals after interpolation, normal mapping and face-forwarding. Depth is camera-axis distance in meters, infinity on a miss. The mask identifies geometric first hits. Empty scenes cannot expose the renderer's internal grid sentinel as geometry.

Selected PNG previews are written for Beauty, Diffuse, Specular, Emission, Normal and Depth. Radiance previews use the existing ACES approximation followed by sRGB. Normal displays `(N+1)/2`; depth is white-near/black-far over the frame's finite depth range, recorded in the manifest. A constant-depth visible surface displays white. Alpha comes from rendered coverage. The NPZ preserves linear values, signed normals and true meter depth independently of preview transforms. Selecting no PNGs still writes all numerical data and the manifest.

## Native UI and public commands

Open Render in the 3D Scene toolbar, or Scene Preview Batch in Rendering. Choose a new output folder, size 16–1024, and integer start/end satisfying `0 ≤ start ≤ end ≤ 3600`. Pass buttons toggle the PNG outputs; existing AOV menu selections initialize the panel. Render starts the job. The panel shows state and completed/total frames, and exposes Cancel job. Closing the panel leaves the job running; cancellation takes effect after the current frame. A completed output cannot be overwritten. These rendering controls do not mutate authored meshes, materials, lights or history.

Public commands are `scene.render_start(destination, size=256, first=0, last=0, channels=None)`, `scene.render_status()` and `scene.render_cancel()`. Every response nests state under `job`; failed/cancelled job diagnostics remain inside that envelope so the command executor does not misinterpret a successful status read as a failed command. Channels are unique lowercase supported names; omitted means all PNGs, empty means numerical-only. Jobs snapshot the authored state, reject simultaneous starts, stage output in a sibling temporary directory, and publish after all frames and the manifest succeed. Failure/cancellation removes the staging directory. The job has a stable random ID and records its destination, progress and result/error.

## Native/API evidence

Use separate copies of the verified scene-lighting GUI and Aether cube projects. Set the API camera explicitly to the GUI Top view: target (0,0,0), distance 10, yaw 0, pitch π/2, orthographic projection, scale 6.5. Native GUI Render writes frames 0–2 at 128 pixels, all passes. Independently start the same public API job. All PNG bytes and every numerical pass array match exactly across all three frames. The first comparison used a Perspective API camera; preserve that failed comparison and its output rather than loosen the image comparison.

The flat top-face normals are +Y; depth is positive finite meters on hits and infinity elsewhere. Maximum linear radiance reconstruction error is 1.1026859283447266e-6 (gate 2e-6). Native source/material/light inspections before and after render/cancel are exact. A native 512-pixel job for frames 0–30 was cancelled through the UI after seven frames; neither final output nor staging files remain. Independent API cancellation after one frame also reports cancelled successfully. The earlier top-level error-envelope defect and its correction are recorded. On the final candidate, native pass selection writes only Normal and Depth PNGs plus NPZ/manifest for a 64-pixel frame.
