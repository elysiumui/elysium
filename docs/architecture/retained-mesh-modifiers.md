# Retained mesh modifiers — implementation decision

A placement keeps its owned editable mesh revision as the source. `props.modifiers3d` is a validated schema-1 ordered stack with a monotonic identity counter and entries containing stable ID, kind, enabled flag and typed parameters. Evaluation produces geometry without replacing the source key. The initial algorithms are Mirror, Array and Simple Solidify; remaining required algorithms retain their acceptance scope.

The native scene renderer, exporter and viewport share `mesh_edit.evaluate`. The legacy taper evaluates before the stack. Modifier edits evaluate the complete candidate before publishing one undoable property change. Component edits continue to target source identities; source points/edges form the editable overlay and generated surfaces cannot be selected as authored components before applying. Stack changes participate in the viewport render key.

Apply stack bakes enabled entries (and the existing taper) into a new owned source, discards disabled entries and clears the stack. Object Apply transforms continues to transform the source while retaining the modifier stack; it does not accidentally bake generated copies twice. Save/reopen validates and persists source assets and stack properties independently.

Mirror supports one local axis and a plane offset, with optional merging of vertices within the documented distance to that plane. Array supports 1–64 copies with absolute local XYZ offset. Source/copy corner UVs, normals, materials and edge flags remain; reflection reverses winding and transforms normals. Intermediate stack evaluation is limited to one million vertices/edges/corners in aggregate to reject exponential copy growth before allocation.

Solidify supports signed nonzero thickness, offset from -1 to 1 and optional boundary rims. Each vertex moves along the normalized angle-weighted sum of its incident face normals. Outer and inner surfaces keep corner attributes; inner winding and custom normals reverse, and generated rim faces inherit the adjacent face material and boundary UV coordinates. Source and copied edges retain seam/sharp flags. Negative thickness reverses the shell winding to keep its outside orientation. Input must be an oriented edge-manifold surface with one connected face fan and a defined normal per vertex. Loose geometry and non-manifold input are rejected before publication. This is Simple mode without even-thickness correction, thickness clamping, intersection repair, material offsets or vertex groups. Those variants remain open. Reference semantics: [Blender Solidify manual](https://docs.blender.org/manual/en/5.0/modeling/modifiers/generate/solidify.html); actual Blender comparison remains pending.

Taper updates and Apply transforms validate the prospective complete evaluation before changing properties or binding geometry. This prevents a transform that collapses Mirror-merged faces, or a taper with zero axial extent, from leaving an unevaluable stack.

Code checkpoint: 223 Designer tests and 277 targeted framework tests pass. Tests include source/evaluated separation, modifier order/bypass/apply and Undo, saved-project reopening, positive/negative Solidify shell volume and winding, rim bypass, edge attributes, invalid-input atomicity, registered public handlers and export of both mirrored copies while saving only the editable source plus stack. These are code-level checks, not a GUI-authored acceptance matrix.

Pending acceptance: actual GUI and public-Aether independent authoring against GUI-authored Blender modifiers, clean-process GUI reopen, broader merge/axis/order combinations, other required algorithms and full performance/visual checks. The Mac locked before these GUI checks; passing code tests do not close the modifier family.

## Discrete subdivision checkpoint

Subdivision adds 1–4 levels of Catmull–Clark or Simple refinement. Each polygon becomes one quad per corner. Face points are corner-position averages; interior edge points average endpoints and adjacent face points; Catmull–Clark interior vertices use `(F + 2R + (n-3)P) / n`. Boundary vertices use `0.75P + 0.125(B0+B1)`, with optional preservation of corners incident to one face. Simple mode leaves original positions and uses edge midpoints. Input must have consistently oriented manifold edges, a single connected surface fan per vertex, and one named part per face. Loose geometry is rejected before publication.

Source vertex IDs persist in the evaluated mesh; split edges inherit seam/sharp flags; generated quads inherit material slots. Face-varying corner UVs use linear interpolation separately inside each source polygon, so seams stay separate. Custom corner normals are interpolated and renormalized. The complete requested level count is preflighted against the one-million-component limit before intermediate subdivision allocation.

This checkpoint does not project onto the infinite limit surface, implement crease weights, offer UV smoothing modes, or certify all boundary/extraordinary-vertex cases. Reference semantics: [Blender subdivision manual](https://docs.blender.org/manual/en/3.6/modeling/modifiers/generate/subdivision_surface.html).

The independently GUI-authored Cube fixture uses one Catmull–Clark level, Boundary All, Blender Use Limit Surface off, Use Creases off and UV Smooth None. Designer GUI, public Aether and Blender GUI agree on 26 vertices / 48 edges / 24 quads with exact connectivity/winding and maximum Blender position error 5.0001e-8 m. The source remains 8/12/6. Clean-process native Designer reopen preserves the exact source, settings and evaluated topology. Simple mode, higher levels, boundary options, face-varying UV islands and custom normals have code tests; additional GUI matrices remain open.

Solid viewport shading now uses one transformed polygon normal for all render triangles within an authored polygon. This removes diagonal shading seams on nonplanar subdivision quads without changing mesh geometry, hit identities or material-preview shading. The regression renders a nonplanar quad, verifies both triangles are visible and requires a single flat shade. Native viewport inspection passed after rebuilding and installing the candidate. Latest checks: 224 Designer tests and 296 targeted framework tests.
