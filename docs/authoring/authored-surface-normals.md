# Authored surface normals

The triangle material renderer interpolates authored vertex normals with hit barycentric weights, then normalizes them. Normals transform by the inverse transpose of the object's linear transform; translation does not affect them. Absent or zero normals fall back to the geometric face normal. Singular transforms produce zero normal fallbacks rather than NaNs. Material shading still faces the resulting normal toward the viewing ray.

Scene composition preserves evaluated normals across object/hierarchy transforms and reflected winding. Meshes without authored normals retain zero fallbacks when composed with smooth meshes. It does not duplicate, move, or reorder geometry to implement shading. Solid preview uses the same interpolation, with one source-polygon normal as its flat fallback, preserving the earlier fix for visible triangulation diagonals on nonplanar quads. Checker preview, ray intersections, depth, and picking remain geometric.

Verification: 84 related framework tests and 245 Designer tests pass. Actual native Designer creation of a radius-1 sphere (32 segments, 16 rings), Solid/Material switching, and project save were exercised. An independently created Blender GUI sphere uses matching dimensions and Shade Smooth. Both have 482 vertices and 512 oriented polygons, matching vertex positions within 1.282e-6 meters. The Designer primitive's radial normals differ from Blender's polygon-derived normals by up to 0.005995 vector units. This fixes rendering of existing authored normals; it does not certify full normal-authoring, studio-light, or visual parity.
